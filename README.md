# Pulsea — экран ресепшена

Учебное задание: клиенты, абонементы и отметка посещений. Данные из моков, хранятся в состоянии приложения.

## Запуск

Нужен Node.js (24.14+).

```bash
git clone https://github.com/<логин>/<репозиторий>.git
cd <репозиторий>
npm install
npm run dev
```

Откройте http://localhost:5173/.

## Сборка

```bash
npm run build && npm run preview
```

## Допущения

- «Сегодня» — локальная дата браузера.
- Срок абонемента = сегодня + число дней тарифа.
- Данные не сохраняются при перезагрузке страницы.
